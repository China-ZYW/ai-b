# AI 数据助理 · 用户手册

> 用一句话提问，就能查数据、出图表、看懂结论。
> 本手册覆盖系统全部功能，按"从入门到治理"的顺序编排。左侧目录支持锚定定位（见第二十章），点击直达任意章节。

---

## 一、产品能做什么

AI 数据助理把**自然语言问数**作为核心入口：你用中文描述想看的数据，系统自动选择相关表、生成 SQL、只读执行、推荐图表，并给出 **AI 数据解读** 与 **质量校验** 结论。

围绕这一入口，产品提供五条能力主线：

- **取数**：对话问数、多轮追问、结果导出、历史回放、收藏复用。
- **沉淀**：把验证过的问法固化为**指标**，一次沉淀、长期复用；可在语义层维护业务别名与口径，让系统越用越懂你的业务。
- **呈现**：把多个指标/图表组合成**驾驶舱**，可一键布局、可背景与主题自定义、可生成免登录的公开大屏链接。
- **协作**：以**组织（租户）**为单位共享数据源与成果，按角色分工，并提供邀请加入、成员管理、操作审计、智能预警。
- **治理**：多层数据安全机制（角色权限、行级范围、字段级脱敏、问数护栏），以及供管理员使用的配额、席位、模型与平台配置。

### 1.1 五类角色的视角

| 角色 | 关注什么 | 建议从哪一章读起 |
| --- | --- | --- |
| 业务人员 | 提问查数、看图表与解读 | 第六章 对话问数 |
| 数据分析师 | 沉淀指标、调优准确率 | 第七章 指标库、第十二章 问数调优 |
| 大屏制作人 | 驾驶舱布局与视觉、公开分享 | 第八章 驾驶舱 |
| 组织管理员 | 成员、邀请、审计、预警 | 第十四章 组织协同 |
| 平台管理员 | 租户、配额、模型、全局配置 | 第十八章 平台后台 |

## 二、5 分钟快速上手

如果你只想尽快看到效果，按这个最短路径走一遍：

1. **接入数据源**：左侧「数据源」→ 新建 → 填主机端口库名账号密码 → **测试连接** → 保存。（也可以直接上传 Excel / CSV）
2. **问第一个问题**：左侧「对话问数」→ 选中刚建的数据源 → 输入 `各地区本月销售额排行` → 回车。
3. **读结果**：看图表 → 需要细看就切「明细」→ 看右侧/下方的**AI 数据解读**与**质量校验**结论。
4. **存为指标**：结果区点「存为指标」，下次在「指标库」一键刷新，不必重复提问。
5. **搭个大屏**：左侧「驾驶舱」→ 新建 → 拖入指标 → 点「AI 自适应布局」或「AI 智能设计」→ 保存 → 预览。

> 提示：问不出结果时，先看「质量校验」给出的改进建议；必要时到「问数调优」补充语义层别名与口径说明。

## 三、登录、注册与加入组织

### 3.1 登录

打开系统地址，输入账号密码登录。**密码错误会直接在页面上提示"用户名或密码错误"，不会刷新或跳转页面**，你可以立即更正重填。

### 3.2 自助注册

点击登录页的注册入口，填写用户名、密码（6-64 位）、昵称与邮箱后提交。注册成功后系统会为你开通一个工作区（组织），你即为其所有者（OWNER）。

> 注意：如果你是通过**同事发来的邀请链接**首次使用，请不要走自助注册——自助注册会额外开一个新的工作区。正确做法是走 3.3 的"用邀请注册"。

### 3.3 通过邀请加入组织

被邀请者打开邀请链接可**免登录预览**邀请概要（组织名、邀请角色、有效期），随后有两种加入方式：

- **已有账号**：登录后点击「接受邀请」，即刻加入该组织并获得邀请指定的角色。
- **还没有账号**：点击链接页的注册按钮，注册时会携带邀请令牌，系统会**在邀请所属组织内**建立账号并自动接受邀请，不会再新建多余工作区。注册成功后直接进入系统。

### 3.4 归属多个组织

同一自然人可以同时属于多个组织（例如本公司 + 客户的协作空间）。各组织是相互隔离的数据空间：切换组织后，数据源、指标、驾驶舱、会话均随之切换，无需重新登录。切换入口见第十五章。

## 五、数据源：接入你的数据

数据源是问数的地基。进入左侧「数据源」→「新建数据源」，支持两大类。

### 5.1 数据库类

支持 MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、Hive、Presto 等 JDBC 数据源。

需填写：**名称、主机、端口、数据库名、用户名、密码**。点击「**测试连接**」验证连通性与账号可用性后再保存。

建议：

- 给数据源起一眼能认出的名字（如"线上交易库-只读"），问数时你会在下拉框里反复看到它；
- **使用只读账号**：系统本身只会执行 SELECT，但用只读账号能从根上避免误写风险。

### 5.2 文件类（Excel / CSV）

上传本地文件后，系统会解析出**工作表清单**：

- **多工作表导入**：Excel 的每个工作表可单独勾选导入，一张工作表对应一张数据表。首行为空的工作表（封面页 / 说明页 / 空表）会被**自动跳过并置灰提示**。
- **同构合并**：若多张工作表列结构完全一致（如 12 张月度表），可开启「合并同构工作表」，系统会纵向合并为一张表，方便跨月一次性聚合。
- CSV 只有一个数据表，无需勾选。

编辑已有文件数据源时，若未重新上传文件，界面会回显"已保存的导入范围"；要更改勾选范围需重新上传文件。

### 5.3 跨库联合分析

在「跨库联合」一栏可勾选/填写同一服务器上的其它库（模式）。配置后，除主库外这些库的表也会进入问数范围，从而支持"一条问题同时查两个库"的联合分析。

- **主库的表名保持原样**（不带前缀），额外库的表名带「库名.」前缀；
- 库名写错或账号无权限时，只会跳过该库，**不影响主库正常问数**。

## 六、对话问数：核心入口

进入「对话问数」，先选择数据源，再在输入框用中文提问。

### 6.1 提问示例与技巧

| 想看的 | 可以这样问 |
| --- | --- |
| 排行 | `各地区本月销售额排行` |
| 趋势 | `近 6 个月订单量趋势，用折线图` |
| 占比 | `统计每个部门的人数，饼图展示` |
| 对比 | `今年与去年同期各品类的销量对比` |
| 单值 | `今天的订单总额是多少` |

技巧：

- **说清时间范围与粒度**，比"最近的数据"更容易命中；
- **直接点名图表类型**（"用柱状图""饼图展示"）可跳过推荐环节；
- 一次只问一件事，复杂诉求拆成几个问题，准确率更高；
- 业务黑话可以在「问数调优 → 语义层」配别名，或在「术语词典」配映射，之后就能用口语词提问。

### 6.2 一次问数经历了什么

系统会依次完成：**理解意图 → 选择相关表 → 生成 SQL → 安全校验 → 只读执行 → 推荐图表 → 质量校验 → AI 解读**。

其中几步的设计：

- **确定性优先**：命中指标、样例、数据字典等确定性能力的问法会**直接复用已验证结果**，既快又不消耗配额；只有确实需要时才调用大模型。
- **免核桃具安全校验**：生成的 SQL 必须是安全的单条 SELECT；
- **失败自愈**：执行报错时会让模型依据报错自我修正并重试（有次数上限）。

### 6.3 结果面板

- **图表 / 明细切换**：结果区可在图表与明细表之间切换，明细表支持分页翻阅全量行；
- **查看 SQL**：可展开查看系统生成的 SQL 并一键复制，便于自己复核或交给 DBA；
- **完整度信息**：展示是否被截断、真实总行数、是否经过修复重试、以及置信度等。

### 6.4 图表设置

点击结果面板的「图表设置」，可自定义：

- **X 轴 / Y 轴名称**；
- **度量单位**（元 / 件 / % / 次 等），单位会拼进轴名与数值标注；
- **数值格式**（紧凑 K/M、千分位、普通）与**小数位**；
- **图例位置**（上 / 下 / 左 / 右 / 隐藏）。

未手动设置时，系统按「语义层单位 → 列名关键词（金额/数量/率）」自动推断单位与格式。这些设置可在"存为指标""分享"时一并带走。

### 6.5 AI 数据解读

系统用自然语言给出**一句话结论、关键要点（趋势 / 对比 / Top 项）、异常提示**，帮你从"看到数据"走到"看懂数据"。历史会话回放时会**一同还原**这部分解读。

### 6.6 质量校验

系统会复核"结果是否真正回答了你的问题"，给出**质量分、发现的问题、改进建议**。若校验判定未达标，系统会依据校验意见**重新生成一次 SQL** 并取更优结果。

### 6.7 多轮追问

同一会话内可连续追问，系统会补全省略式问法：`那上个月呢`、`只看电子类`、`换成柱状图` 都能正确承接。

### 6.8 拒答护栏与敏感字段

- **域外护栏**：明显的寒暄闲聊会被友好快速拒答，既不消耗配额，也不会对着"你好"生成一条无关 SQL。
- **权限护栏**：如果你问的问题点名了当前角色无权查看的敏感字段，系统会**前置友好拦截**——这是"前置拦截 + 结果层脱敏"双保险中的第一道。

### 6.9 会话的管理

左侧「最近会话」保留你的历史对话，点开可继续追问，也可回放历史轮次的完整结论（图表、解读、质量校验一并还原）。会话可重命名、删除。

## 七、指标库：沉淀常用问法

在问数结果区点击「**存为指标**」，可把当前问法、SQL、图表与样式固化为一个**指标**。

在「指标库」中你可以：

- **一键刷新**：重跑指标已存 SQL 查看最新数据（**不消耗大模型额度、不计配额**）；
- **维护元信息**：别名、描述、所属分类；
- **维护图表样式**：轴名 / 单位 / 数值格式 / 图例（与第六章 6.4 一致）；
- **被引用**：指标是驾驶舱大屏的基本组成单元。

> 展示别名：指标列表与明细优先使用「语义管理」中配置的业务别名展示，没有别名时用列名兜底。

**为什么值得沉淀**：同一个经营口径，走指标永远比重新问一遍更稳——指标复用的是**已验证过的 SQL**，不会今天问一个答案、明天问另一个答案。

## 八、驾驶舱与大屏

进入「驾驶舱」，可把多个指标组合成一屏可视化看板。

### 8.1 三种创建方式

1. **新建空白驾驶舱**：从零拖拽搭建，最灵活；
2. **一键自动布局**：勾选若干指标直接生成均衡网格驾驶舱，适合快速起步；
3. **从模板实例化**：套用平台内置或自建模板的骨架布局，再按顺序绑定指标，适合有固定版式的汇报场景。

### 8.2 画布编辑

左侧指标面板可拖入或点击加入画布，画布为 **12 列网格**，组件可自由拖拽位置、拉伸大小。

顶部可配置：**名称、主题（深/浅）、列数、刷新频率（秒）、是否数据大屏**。

大屏按视口**整屏铺满**：无论放 4 个还是 8 个图表，都同屏显示、不需要翻页滚动。

### 8.3 AI 自适应布局（确定性算法）

点击「**AI 自适应布局**」，系统会依据每个组件的**真实数据形态**重新排布：

| 数据形态 | 系统会怎么处理 |
| --- | --- |
| 单行单值的指标 | 排成一行小卡片（指标卡），置于顶部 |
| 时间点多 / 系列多的趋势 | 占满整行，避免折线被压扁 |
| 类目很多的排行 | 自动加高，保证每一条都看得见 |
| 行数或列数多的明细表 | 占满整行并置底 |
| 类目标签很长 | 自动加宽，避免标签被截断 |
| 占比类（饼图/漏斗/雷达） | 按类目多少给 1/3 或 1/2 幅宽 |

特点：**零延迟、不消耗配额、结果稳定可预期**。排布后可通过提示消息看到本次的判定摘要（如"2 个指标卡、1 个趋势、1 个明细"）。

### 8.4 AI 智能设计（大模型自定义布局 + 样式填充）

点击「**AI 智能设计**」，可在以上确定性布局之上再叠加一次**大模型设计**：弹出框中可输入风格指令（如"科技感深色，把 GMV 趋势放在最显眼位置"），留空则由模型自行判断。

系统会：

1. 先把各组件的**数据形态摘要**（行数 / 类目数 / 系列数 / 标签长度，不含任何明细数据）与 8.3 的基线布局发给后端；
2. 由大模型产出**语义分组更合理、主次更分明**的布局，以及一整套**视觉样式**（顶栏背景、卡片背景、边框、强调色、文字色、字体、字号比例、圆角）与**整屏背景**；
3. 后端对结果做**严格校验**（是否覆盖全部组件、有无越界、有无重叠、颜色值是否合法 CSS），非法即整体丢弃；
4. 前端应用通过校验的方案。

> **失败不影响使用**：大模型未配置、调用超时、输出非法时，会自动**沿用 8.3 的确定性算法布局**并如实提示回退原因。也就是说"AI 智能设计"按钮在任何情况下都可用，最差等价于按一次"AI 自适应布局"。

> **隐私边界**：发给大模型的只有形态摘要与组件标题，**绝不包含业务明细数据行**。

### 8.5 背景与自定义样式

- **整屏背景**：上传图片后系统自动写为背景样式；也可直接填写色值或渐变 CSS。
- **大屏级样式**：字体族、字号比例（0.8~1.4×）、卡片圆角（0~24px）、顶栏背景、卡片背景、边框、强调色与三级文字色，均可逐项覆盖所选主题。
- **组件级样式**：每个 widget 可单独覆盖卡片背景、边框、标题色、圆角与强调色，用于突出关键卡片。
- **组件级图表设置**：轴名 / 单位 / 数值格式 / 图例，同一指标被多处引用时可各自设定且互不影响。

自定义样式在**编辑态画布、全屏预览、公开分享页**三处一致呈现。

### 8.6 保存、预览与投放

- 点「保存」把布局与样式落库；点「大屏预览」查看真实全屏效果；
- 标记为「数据大屏」的驾驶舱拥有独立的全屏投放页，按设定的**刷新频率（秒）**轮询拉取最新数据，适合投在大屏电视上长期运行。

### 8.7 公开分享

驾驶舱可生成**公开分享链接**：凭链接免登录访问，可设置**访问密码**与有效期，随时可撤销。适合给外部伙伴或异地同事看同一块屏。

## 九、查询历史与回放

进入「查询历史」，可回顾你问过的每一次数据：

- 列表展示**问题、数据源、状态、行数、耗时、时间**；
- 点击「详情」进入**历史回放**：还原问数当时的**结果数据、图表、AI 数据解读与质量校验结论**；
- 老记录若无结果快照，系统会**重跑已存 SQL** 回放（不消耗大模型额度、不计配额）；
- 可对历史**点赞 / 点踩**——被点赞的成功问答会进入少样本样例库，让系统越用越准；也可删除历史。

> 若数据源已被删除或结构发生变更，结果可能无法回放，但仍会显示问数当时的解读与校验结论。

## 十、我的收藏

把常用问法收藏起来，在「我的收藏」中一键重跑或取消收藏，不必每次重新组织语言。

---

## 十一、分享管理

把某次问数结果生成分享链接：

- 可设置**访问密码**与**有效期**；
- 被分享方凭链接**免登录**查看结果与图表；
- 在「分享管理」中可查看全部分享、撤销（立即失效）或续期。

## 十二、问数调优（进阶）

「问数调优」面向希望提升问数准确率的用户与管理员，包含四块。

### 12.1 语义层

维护表/字段的**业务别名、口径说明、枚举取值、是否敏感列**，让系统用你业务的词汇理解数据（例如把 `amt` 叫做"金额"、给 `status` 写清`1=已支付`）。

- 别名会体现在**结果展示名、图表轴名**上；
- 单位（元/件/%）写在这里，图表自动带上度量单位；
- 标记为**敏感**的列配合"可见角色"，是字段级脱敏的依据（见第十六章）。

### 12.2 少样本样例

把典型「问法 → SQL」成对教给系统。命中后直接复用已验证 SQL，**免大模型、免配额、口径稳定**。

### 12.3 术语词典

把口语词映射为规范名（如"流水" → "营收"），让同义异词也能命中确定性能力。

### 12.4 图表推荐规则与默认配置

调整各类图表的推荐触发规则，以及图表标注、单位等默认值；租户可在平台默认之上做个性化覆盖。

## 十三、智能预警

配置基于数据的预警规则（如"日活低于阈值时提醒"）：系统按规则周期性计算指标当前值，命中即产生预警记录，并支持通知与审计留痕。适合把"每天看一次"变成"异常才找我"。

## 十四、组织协同（仅 OWNER / ADMIN 可见）

组织内 OWNER（所有者）与 ADMIN（管理员）可在左侧看到「组织成员 / 组织邀请 / 组织审计 / 智能预警」页面。

### 14.1 组织成员

查看组织内所有成员及其角色，管理员可**调整成员角色、移除成员**。系统会阻止"移除自己"与"移除最后一个所有者"等危险操作。

### 14.2 组织邀请

生成邀请链接或令牌发给同事：

- 支持**定向邮箱**（仅限该邮箱接受）与**邮箱域限制**（仅限某域名邮箱）；
- 支持**席位上限**与**有效期**，到期或用尽即失效；
- 可随时**撤销**邀请。

### 14.3 组织审计

查看本组织的操作审计日志：**动作**（登录、权限拒绝、邀请创建/接受、席位变更等）、**操作人**、**被操作对象**、**资源**、**IP**、**结果**与**时间**，便于追责与合规核查。

## 十六、数据安全与权限

平台内置多层安全机制，数据在返回前即按权限裁剪。

### 16.1 角色与权限点

| 层级 | 角色 | 决定什么 |
| --- | --- | --- |
| 平台 | SUPER_ADMIN / OPERATOR / AUDITOR / SUPPORT | 后台管理可见范围 |
| 组织 | OWNER 所有者 | 组织全部权限、成员与席位管理 |
| 组织 | ADMIN 管理员 | 组织内管理与数据范围 |
| 组织 | DATA_STEWARD 数据管家 | 语义层与治理（数据口径把关） |
| 组织 | ANALYST 分析师 | 问数、指标、驾驶舱 |
| 组织 | VIEWER 查看者 | 只读查看，不可改写资源 |
| 组织 | BILLING 财务 | 配额与席位账单相关 |

每个页面与接口都挂有权限点：**前端按权限点过滤菜单，后端再做强校验**——前端展示不是安全边界。

### 16.2 行级数据范围

业务库对平台**只读**，行级数据不归平台管理；平台在**结果层**按语义层配置施加数据范围约束（如仅可见本人/本团队数据），越权访问会被拒绝并记录审计。

### 16.3 字段级脱敏（敏感列）

语义层标记为"敏感"的列（如手机号、金额），仅在**被授权角色**（`可见角色`）下返回真实值；未授权角色看到的是**脱敏后的结果**，原始值不返回。与"权限护栏前置拒答"共同构成双保险。

### 16.4 审计留痕

登录、鉴权拒绝、数据访问、邀请、席位与权限变更等关键动作均留有审计日志，平台侧可跨租户检索（见 18.10）。

## 十七、配额与用量

- 每次**调用大模型的问数**计入配额；

- 管理员可在后台查看用量统计并调整每日/累计额度。

## 二十二、常见问题

- **问数结果不对怎么办？** 先看「质量校验」的问题点与改进建议；可在「问数调优」补充语义层别名与口径，或把正确问法存为少样本样例。
- **为什么同一问题两次结果不同？** 若走的是大模型实时生成，措辞差异可能导致 SQL 不同。解决办法：把验证过的问法**存为指标**，之后复用同一条 SQL。
- **额外库配了却问不到？** 确认库名拼写正确、连接账号对该库有权限；库名错误只会被跳过。
- **Excel 某些工作表没导入？** 首行为空的工作表会被自动跳过；请确保首行是列名，或把多余表头行删掉。
- **历史回放看不到图表？** 若数据源已被删除或结构变更，结果无法回放，但仍会显示问数当时的解读与校验结论。
- **最近会话里没有 AI 解读 / 质量评分？** 解读与评分是问数当时生成并随结果保存的；极老的记录或当时关闭了这两项 AI 能力的会话不会显示。
- **接受邀请报错？** 确认邀请未过期、席位未用尽；新账号请用邀请链接里的注册入口，会在邀请所属组织内建立，不会新建多余工作区。
- **大屏背景不显示？** 背景图需通过大屏编辑页上传后保存；图片由后端素材接口提供，需后端正常运行才能加载。
- **点了 AI 智能设计却提示回退？** 说明大模型未配置、超时或其方案未通过合法性校验，此时已自动应用确定性算法布局，可直接使用；也可让管理员检查「大模型配置」。
- **看不到某个菜单？** 菜单按权限点过滤，请向组织管理员申请对应角色。

## 二十三、术语表

| 术语 | 含义 |
| --- | --- |
| 数据源 | 一个可查询的数据库或文件，问数的对象 |
| 指标 | 一条固化的问法（含 SQL 与图表配置），可反复刷新复用 |
| 驾驶舱 / 大屏 | 由多个指标组件组成的一屏看板，可公开分享 |
| widget / 组件 | 驾驶舱中的一个图表单元 |
| 语义层 | 表与字段的业务注解（别名、口径、枚举、单位、是否敏感） |
| 少样本样例 | 「问法 → SQL」成对样例，命中后直接复用已验证 SQL |
| 会话 | 一次连续的多轮对话上下文 |
| 租户 / 组织 | 相互隔离的数据与协作空间 |
| 席位 | 组织成员数上限 |
| 配额 | 允许调用大模型的问数次数 |
| 脱敏 | 对无权限角色隐藏原始值，仅返回遮蔽后的结果 |
| 护栏 | 在问数前拦截无关提问或越权提问的保护机制 |
