# aibi 本地启动与联调手册

> 面向"第一次把项目跑起来"的用户。仓库根的 [README.md](../../README.md) 有 30 秒版入口，本文补充端口/健康检查/常见故障排查。

---

## 1. 环境依赖

| 组件 | 版本 | 说明 |
|------|------|------|
| JDK | **17+**（必须） | 系统默认为 JDK 8 时会让 maven-compiler-plugin 报 `invalid flag: --release`；显式设 `JAVA_HOME` 指向 JDK 17+ |
| Maven | 3.8+ | Windows 用 `mvn.cmd`（Git Bash 会调 sh 脚本导致 `ClassNotFoundException: Launcher`） |
| Node.js | 18+ | 前端构建；`npm install` 后即可 `npm run dev` |
| MySQL | 5.7+ / 8.x | 平台元数据库 `aibi_meta`；`createDatabaseIfNotExist=true` 允许首连自动建库 |
| LLM API Key | DeepSeek / 通义千问 任一 | 无 Key 时只影响"问数"，其余功能仍可跑通 |

### 凭据注入

`application.yml` **不含任何真实默认值**。本地凭据写在 `backend/local.env`（gitignore，参照 `backend/local.env.example` 新建），由 `SecretsGuardEnvironmentPostProcessor` 启动时读取并校验：

- 必需项：`AIBI_DB_URL` / `AIBI_DB_USERNAME` / `AIBI_DB_PASSWORD` / `JWT_SECRET`（≥32 字节）/ `AIBI_CIPHER_KEY`；
- 缺失时**启动即失败**并中文提示缺哪几项；真实环境变量优先于 local.env；
- 生产：`systemd` 用 `EnvironmentFile=/opt/aibi/aibi.env`（权限 600）。

## 2. 三种启动方式

### 方式一：一键引导（推荐首次使用）

```powershell
# Windows
pwsh scripts/init.ps1
```

```bash
# Linux / macOS
bash scripts/init.sh
```

交互式收集必需凭据 → 写 `backend/local.env` → 建库 → 拉起前后端。

### 方式二：手动两条命令

```bash
# 后端
cd backend
mvn -B -DskipTests spring-boot:run

# 前端（新开终端）
cd frontend
npm install
npm run dev
```

Windows PowerShell 5.1 下必须显式设 `SERVER_PORT=8080`（宿主进程可能注入其他端口覆盖 yml 配置）：

```powershell
$env:SERVER_PORT = "8080"
$env:JAVA_HOME = "C:\path\to\jdk17"
mvn -B -DskipTests spring-boot:run
```

### 方式三：打包成 jar 再跑

```bash
cd backend
mvn -B -DskipTests clean package
java -jar target/aibi.jar --server.port=8080
```

## 3. 健康检查（启动成功的判据）

| 检查项 | 命令 / 地址 | 期望 |
|--------|-------------|------|
| 后端存活 | `curl http://localhost:8080/actuator/health` | `{"status":"UP"}`，HTTP 200 |
| 前端可访问 | 浏览器打开 `http://localhost:5173/` | 登录页正常渲染 |
| 代理链路 | `curl http://localhost:5173/api/datasource/list` | **401**（说明 Vite 代理已把 `/api` 转到后端；未带令牌的正确响应） |
| 登录接口 | `POST http://localhost:8080/api/auth/login` | 200 且返回 token |
| MCP 端点 | `GET http://localhost:8080/.well-known/aibi-mcp` | 200 且带 `endpoint` / `tokenMethods` 声明 |

后端启动日志出现 `Started AiBiApplication in ... seconds` 即为就绪。

### 默认账号（首次播种，仅本地/开发）

| 账号 | 默认口令 | 说明 |
|------|---------|------|
| `superadmin` | `[redacted-default-pwd]` | 平台超管，由 `DataSeeder` 首启播种；用 `AIBI_SUPERADMIN_USERNAME` / `AIBI_SUPERADMIN_PASSWORD` 环境变量覆盖 |

> 生产务必**先设环境变量再首次启动**；一旦播种完成，密码修改只能走 UI，无法再靠环境变量覆盖。

## 4. 端口与主要路径

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端 | `http://localhost:5173` | Vite dev server，`/api` 代理到后端 |
| 后端 | `http://localhost:8080` | 上下文路径为空，接口前缀 `/api/**` |
| 健康检查 | `/actuator/health` | — |
| 流式问数 | `GET /api/chat/query/stream`（SSE） | 需 `Authorization` 头，前端用 fetch 而非原生 EventSource |
| MCP 主端点 | `POST /mcp` | 自带 PAT 或外部 IdP JWT；见 [对外 MCP 能力方案](../04-analysis/对外MCP能力方案.md) |
| MCP 发现 | `GET /.well-known/oauth-protected-resource`<br>`GET /.well-known/oauth-authorization-server`<br>`GET /.well-known/aibi-mcp` | RFC 9728 / 8414 / 自描述 |

## 5. 常见故障与处理

| 现象 | 原因 | 处理 |
|------|------|------|
| `invalid flag: --release` | `JAVA_HOME` 指向 JDK 8 | 显式设 `JAVA_HOME` 为 JDK 17+ |
| Git Bash 里 `mvn` 报 `ClassNotFoundException: Launcher` | Git Bash 调了 sh 脚本 | 用 `mvn.cmd` 或切到 PowerShell |
| 后端起在 58713 等奇怪端口 | 环境注入了 `SERVER_PORT` | 启动前显式设 `SERVER_PORT=8080` |
| `Port 8080 was already in use` | 上一实例未退出 | `netstat -ano \| findstr :8080` 找 PID 结束进程 |
| `/api/**` 前端返 500 空响应 | Windows Vite 代理解析 `localhost` 走 IPv6 `::1`，Tomcat 只绑 IPv4 | 前端 `.env.development` 把 `VITE_BACKEND` 指到 `http://127.0.0.1:8080` |
| PowerShell 中文脚本 ParserError | Windows PowerShell 5.1 要求 UTF-8 带 BOM | 用 UTF-8 with BOM 重新保存 .ps1 |
| 缺 LLM Key 时点"问数"报错 | DeepSeek/Qwen 均未配 | 至少配一个 API Key，或暂时用不到问数就不点 |

## 6. 环境限制说明

- **进程内实现**：缓存、配额计数、并发护栏、限流桶均为**进程内实现**（适配单机 4C4G、零外部中间件依赖）。多实例部署前需引入 Redis 平替路径，替换 `CacheService` / `QuotaService` / `ConcurrencyGuard` / `McpRateLimiter`。
- **NL2SQL 完全走 LLM**：无本地模型兜底；LLM 不可用时问数链路 fail-soft 返回降级提示，不影响其他功能。
